### **Aplikasi Kasir Digital untuk UKM LDK FISIP UNMUL**
*بِسْمِ اللَّهِ الرَّحْمَنِ الرَّحِيم*

Warung Al-Ashr adalah aplikasi manajemen Point of Sale (POS) berbasis digital yang dirancang khusus untuk mengelola operasional unit usaha di lingkungan Lembaga Dakwah Kemahasiswaan (LDK) FISIP Universitas Mulawarman. Aplikasi ini berfungsi sebagai platform terpusat untuk mengintegrasikan proses penjualan, pemantauan stok, hingga pelaporan keuangan guna menciptakan tata kelola usaha yang profesional dan transparan.

Aplikasi ini dikembangkan untuk menghilangkan hambatan pengelolaan manual, memastikan setiap transaksi terdokumentasi dengan akurat, serta memberikan data yang valid bagi pengelola dalam mengambil keputusan operasional.

## 🗄️ Skema Database

```sql
profil              → Data profil user (nama, telepon, alamat, is_admin)
produk              → Daftar & stok produk
transaksi           → Header transaksi (total, metode bayar)
detail_transaksi    → Item per transaksi (qty, harga snapshot)
absensi             → Catatan absensi karyawan harian
```

**RPC Functions:**
- `kurangi_stok(p_id, p_qty)` — Kurangi stok produk setelah transaksi
- `ringkasan_bulan(p_bulan, p_tahun)` — Statistik penjualan bulanan

**Row Level Security (RLS):** Setiap user hanya bisa mengakses data miliknya sendiri.

## 🚀 Cara Setup

### 1. Clone & Install
```bash
git clone https://github.com/username/kasir_barokah.git
cd kasir_barokah
flutter pub get
```

### 2. Download Font Poppins
Download dari [Google Fonts](https://fonts.google.com/specimen/Poppins) dan taruh di `assets/fonts/`:
```
assets/fonts/
├── Poppins-Regular.ttf
├── Poppins-Medium.ttf
├── Poppins-SemiBold.ttf
├── Poppins-Bold.ttf
└── Poppins-ExtraBold.ttf
```

### 3. Setup Supabase
1. Buat project baru di [supabase.com](https://supabase.com)
2. Jalankan `supabase_setup.sql` di **SQL Editor** Supabase
3. Matikan atau nyalakan konfirmasi email sesuai kebutuhan:
   > Authentication → Providers → Email → Confirm email

### 4. Isi file `.env`
```dotenv
SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6...
SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6...
```
> ⚠️ `SUPABASE_SERVICE_ROLE_KEY` berbeda dengan `ANON_KEY`. Ambil dari: **Settings → API → service_role secret**

### 5. Buat Akun Admin Pertama
1. Jalankan aplikasi
2. Di halaman Login, **tap logo (ikon toko) sebanyak 5x**
3. Masuk ke halaman **"Daftar Akun Admin"**
4. Isi nama, email, password → selesai!

### 6. Jalankan
```bash
flutter run
```
